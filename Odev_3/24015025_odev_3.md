# DATA TYPES (Veri Türleri)
## Text Type (Metin Türü)
**str**: string veri türünü metinsel ifadeleri kullanmak için alırız.

## Numeric Types (Sayısal Türler)
**int**: Tam sayıları almak için kullanılır.

**float**: Ondalıklı sayıları almak için kullanılır.

**complex**: Karmaşık sayıları almak için kullanılır (1+5j gibi).

Burada "+" operatörünü kullanırken dikkatli olmak gerekir çünkü "+" operatörü farklı veri tiplerine duyarlıdır, "," kullanılması daha sağlıklı olacaktır.

## Sequence Type (Sıra Türü)
**list**: Listedir. Ram'i daha az yormak için kullanılır. "[]" ile kullanılır. 

**tuple**: Listeye benzerdir ancak listedeki bir elemanı rahatlıkla dönüştürebilirken tuple dönüştürülemez. "()" ile kullanılır.

**range**: Sayı dizisi oluşturmaya yarar. Örnek olarak range(7) kullanırsak 0'dan 6'ya kadar bir sayı dizisi oluşturmuş oluruz. 

## Mapping Type (Eşleme Türü)
**dict**: Dictionary'den gelir. Verileri benzersiz anahtar-değer (key-value) çiftleri şeklinde saklar. Anahtarlar üzerinden hızlı erişim sağlar. "{}" ile kullanılır.

## Set Types (Küme Veri Tipleri)
Tekrarsız ve sırasız öğelerden oluşan koleksiyon tipleridir. Yinelenen öğeler otomatik olarak tekilleştirilir.

**set**: Değiştirilebilir bir öğedir. Oluşturulduktan sonra add() ve remove() gibi yöntemlerle eleman ekleyip çıkarılabilir. "{}" ile kullanılır ancak anahtar-değer çiftlerinden oluşmaz.

**frozenset**: Değiştirelemez bir kümedir. Elemanları sonradan eklenip çıkarılamaz. "({})" ile kullanılır.

## Boolean Type 
**bool**: Yalnızca iki değeri temsil eden yerleşik bir türdür. True (doğru) ve False (yanlış) olmak üzere iki değer alabilir.

## Binary Types (İkili Veri Türleri)
**bytes**: Değiştirilemez bir byte dizisidir. b" " şeklinde veya bytes() şekinde kullanılır. 

**bytearrays**: bytearray([]) şeklinde kullanılır. bytes kadar katı değildir. Değişkenlik gösterebilir. 

**memoryview**: Bellek bloklarına doğrudan erişim imkanı sağlayan uygulama arayüzü sağlar. Python'da programların bellek tüketimini izlemek ve optimize etmek için kullanılır.

## Nonetype
Diğer dillerdeki "null" ifadesine yani boşa denk gelir. Bir değişkenin henüz boş olduğunu, hiçbir şeye sahip olmadığını belirtmek için "None" kullanılır.

# Conditionals (if-elif-else)
**"if"** ifadesi bir koşulu (sonucu True veya False olan bir ifadeyi) değerlendirir. Koşul doğruysa, if ifadesinin içindeki kod bloğu çalışır. Koşul yanlışsa, kod bloğu atlanır.

**"elif"** ifadesi "Eğer önceki koşullar doğru değilse bu koşulu dene." demektir. elif ifadesi, birden fazla ifadenin True (doğru) olup olmadıklarını kontrol etmemizi ve kod bloğu doğru olduğu an onu çalıştırmamızı sağlar. İstediğimiz kadar elif kullanabiliriz.

**"else"** ifadesi kendisinden önceki koşullar tarafından kapsanmayan her durumu kapsar. if ve tüm elif ifadeleri False (yanlış) olarak değerlendirildiğinde çalışır.

``` 
   if grade >= 90:
     print("A")
   elif grade >= 80:
     print("B")
   elif grade >= 70:
     print("C")
   elif grade >= 60:
     print("D")
   else
     print("F")
```

# Loops (for,while)
### For
For döngüsü bir dizi üzerinde yineleme yapmak için kullanılır. Bu döbgüler, dizideki her bir öge için bir kod bloğunu bir kez çalıştırır.

```
   n=3
   for i in range(0,n):
     print(i)
   
   output:
    0
    1
    2
```

### While
While döngüsü ile, bir koşul doğru olduğu sürece bir dizi ifadeyi yürütebiliriz.
```
  i=1
  while i < 6:
    print(i)
    i += 1

  output:
   1
   2
   3
   4
   5
```
# Functions (Fonksiyonlar)
Fonksiyon, yalnızca çağırıldığında çalışan bir kod bloğudur. Fonksiyonlar sonuç olarak veri döndürebilir ve kod tekrarını önlemeye yardımcı olur. Python'da bir fonksiyon "def" ve ardından gelen fomksiyon adı ile parantezlerle tanımlanır. 
```
  def toplam_bul(sayilar):
    toplam=0
    for sayi in sayilar:
      toplam += sayi
    return toplam

  liste=[10, 20, 30, 40]
  sonuc=toplam_bul(liste)
  print(sonuc)

  Output:
    100
```
